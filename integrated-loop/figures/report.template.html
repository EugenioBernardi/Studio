Ventral stream — the pipeline that turns a shape into a code

Retina difference-of-Gaussians → LGN → V1 complex (orientation energy, phase-invariant) → V2 angle cells. The V2 stage is where identity becomes explicit: corners of different angle activate different populations.

What distinguishes each shape

The three features the decision layer competes on. Each shape is dominated by a different one — that separation is what makes classification work.

Dorsal stream — MT direction tuning

Adelson–Bergen motion energy pooled into MT pattern cells. Each dial is the population response to one stimulus direction; the needle is MT's estimate.

Pattern separation along the trisynaptic path

Sparsity is set by feedback inhibition in each field, never by a k-winners shortcut. The separation gradient below is emergent — it was not tuned for.

Ripple-paced replay

One index per ripple frame. Which index follows which is carried entirely by the learned CA3 transition weights — the order is never scripted.

Systems-consolidation gradient

Cortex-only recall (hippocampus lesioned) against how much replay the memory has had. The memory becomes hippocampus-independent gradually, as cortico-cortical weight accumulates.

Challenging the front-end with handwritten digits

MNIST is a far harder item set than four synthetic shapes, and it exposes something the shape task could not: with the shipped filters every stage of the hierarchy loses information relative to raw pixels. Same readout throughout (L2-normalised, cosine k-NN), so the comparison isolates the representation.

Pathology — the same circuit, lesioned

Each panel is a dissociation, not a decline: a lesion that degrades everything proves nothing, one that abolishes a capacity while sparing another reproduces a clinical syndrome. All four use the same instruments as the healthy validation.

Visual pathology — perimetry, an emergent illusion, and a hallucination

Field defects are objective: the geometry either respects the meridians or it doesn't. Mach bands and the release hallucination are harder to fake — neither is built in, both fall out of mechanisms that are there for other reasons.

Two hippocampi — why unilateral surgery is survivable and bilateral is not

The task is an arbitrary cross-stream conjunction: the ventral (“what”) half of one stimulus bound to the dorsal (“where”) half of another. Cortex never learned that pairing — cued with the ventral half it completes to its own dorsal half, the wrong partner — so every bar is scored against the cortex-alone floor. What is lateralised is the gain on each stream, in both directions: the return path is as ipsilateral as the path in.

Localisation — two retinas and a real chiasm

A field defect localises a lesion only because the two eyes are wired asymmetrically: nasal fibres cross, temporal fibres do not. With one retina every defect below collapses into “part of the field is missing”. With two, the pattern names the site. Each pair is a static-perimetry sweep — a probe stepped over a 12 × 12 grid and scored by the LGN response, per eye, in the patient’s field coordinates.
