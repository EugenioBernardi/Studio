Ventral stream — the pipeline that turns a shape into a code

Retina difference-of-Gaussians → LGN → V1 complex (orientation energy, phase-invariant) → V2 angle cells. The V2 stage is where identity becomes explicit: corners of different angle activate different populations.

What distinguishes each shape

The three features the decision layer competes on. Each shape is dominated by a different one — that separation is what makes classification work.

Dorsal stream — MT direction tuning

Adelson–Bergen motion energy pooled into MT pattern cells. Each dial is the population response to one stimulus direction; the needle is MT's estimate.

Pattern separation along the trisynaptic path

Sparsity is set by feedback inhibition in each field, never by a k-winners shortcut. The separation gradient below is emergent — it was not tuned for.

Ripple-paced replay

One index per ripple frame. Which index follows which is carried entirely by the learned CA3 transition weights — the order is never scripted.

Systems-consolidation gradient

Cortex-only recall (hippocampus lesioned) against how much replay the memory has had. The memory becomes hippocampus-independent gradually, as cortico-cortical weight accumulates.

Challenging the front-end with handwritten digits

MNIST is a far harder item set than four synthetic shapes, and it exposes something the shape task could not: with the shipped filters every stage of the hierarchy loses information relative to raw pixels. Same readout throughout (L2-normalised, cosine k-NN), so the comparison isolates the representation.
